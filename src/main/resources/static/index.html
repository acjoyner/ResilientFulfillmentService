🎓 System Design & Microservice Learning Objectives
Microservices Resilience

Bulkhead & Circuit Breaker Patterns

Uses Resilience4j to isolate downstream service calls. When failure rates exceed 50% or latency spikes occur, the circuit opens to fast-fail requests, preventing thread exhaustion.

Dual Persistence Strategy

PostgreSQL (SQL) + Redis (NoSQL)

Combines transactional ACID guarantees in PostgreSQL (fulfillment_orders) with high-speed Redis caching (ProductCache, TTL 600s) for low-latency product catalog lookups.

Observability & APM

Dynatrace Metrics & Splunk Logs

Instruments Spring Boot Actuator with Micrometer metrics (Prometheus format) and outputs structured JSON Logback logs with MDC trace IDs for Splunk log aggregation.

Infrastructure Automation

RHEL 8/9 systemd & OpenShift

Includes systemd daemon installer scripts (scripts/rhel-systemd-setup.sh), host diagnostic tools (scripts/rhel-health-check.sh), and OpenShift cloud deployment manifests.
